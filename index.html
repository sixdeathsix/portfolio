От общего ядра до прикладного интерфейса

Модульная корпоративная платформа

Общие механизмы для корпоративных систем и интерфейсы для работы с данными. Моя часть — серверное ядро на Laravel и прикладные экраны на React.

  • Laravel
  • React
  • TypeScript
  • PostgreSQL

Задача

Вынести повторяющиеся механизмы в общее ядро, чтобы прикладные модули могли использовать их и добавлять собственную бизнес-логику.

Что нужно было учесть

Единый контракт API для разных сущностей, поиск и сортировку по связанным таблицам, зависимые поля форм и обработку данных на сервере.

Решение

Общая основа. Своя логика у каждого модуля.

На сервере

Базовые CRUD-контроллеры, общая валидация и формат ответов. Фильтрация, сортировка и пагинация через Eloquent и Spatie Query Builder. Условия фильтров задаются в конфигурации сущности.

В интерфейсе

Формы с зависимыми полями и клиентской валидацией. Таблицы с серверными фильтрами, сортировкой и пагинацией. Отдельный пользовательский сценарий в Telegram Mini App.

Frontend в действии

Работа с данными на одном экране

Демонстрационный интерфейс по мотивам рабочих задач. Данные вымышлены, фильтры работают локально.
